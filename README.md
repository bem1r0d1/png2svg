# png2svg

Конвертер PNG → SVG высокого качества, заточенный под Figma: без «лесенок», цветной каймы на краях, щелей между фигурами и мусорных точек.

**Онлайн-версия:** https://bem1r0d1.github.io/png2svg/ — конвертер прямо в браузере (всё считается локально), там же Figma-плагин (zip) и отчёт качества.

Архитектура и план разработки: [docs/PLAN.md](docs/PLAN.md)

## Структура

| Путь | Что это |
|---|---|
| `crates/core` | Ядро на Rust: весь пайплайн конвертации (без зависимостей) |
| `crates/cli` | CLI `png2svg` |
| `crates/wasm` | WebAssembly-обёртка для Figma-плагина |
| `packages/figma-plugin` | Figma-плагин: UI + WASM в Web Worker, вставка вектора на место картинки |
| `crates/metrics` | Рендер SVG обратно (resvg) и метрики качества: SSIM, ΔE OKLab; бенчмарк по корпусу |
| `corpus/src` | Эталонные векторные исходники; `corpus/png` — растры, полученные из них |
| `corpus/baseline.json` | Базовые метрики; CI падает при регрессии качества |

## Быстрый старт

```sh
cargo build --release
./target/release/png2svg logo.png -o logo.svg --metrics
./target/release/png2svg icon.png -p icon -s 0.7      # пресет и гладкость
./target/release/png2svg --help
```

## Figma-плагин

```sh
cd packages/figma-plugin
npm install
npm run build        # собирает WASM и dist/code.js + dist/ui.html
npm test             # движок в Node + UI-смоук в Chromium
```

В Figma Desktop: **Plugins → Development → Import plugin from manifest…** → `packages/figma-plugin/manifest.json`.

Как пользоваться: выделите слой с картинкой (или перетащите PNG в окно плагина), подберите пресет и ползунки — превью обновляется сразу; режим «Сравнить» показывает оригинал и вектор со шторкой. «Заменить» вставляет вектор ровно на место картинки (оригинал скрывается, не удаляется), «Вставить рядом» — справа от неё. Слои называются по цвету (`color-1a2b3c`), а цвета, совпадающие с локальными Color Styles / Variables (ΔE < 2), к ним привязываются.

Всё считается локально в WebAssembly, сеть плагину не нужна.

## Сайт

`./scripts/build-site.sh` собирает `site/` (веб-версия, zip плагина, отчёт). При пуше в `main` workflow **Pages** публикует его в ветку `gh-pages`.

## Как работает пайплайн

0. **Очистка входа** — оценка шума (лапласиан) и билатеральный фильтр; депикселизация: поиск пиксельной сетки увеличенных картинок → трассировка логического изображения (для pixel art — через Scale2x); сглаживание краёв по качеству входа (ступеньки, размытие, шум). Результат гладкий при любом масштабе.
1. **Детекция антиалиасинга** — пиксели, являющиеся смесью двух соседних цветов, помечаются и не участвуют в построении палитры (нет «бахромы» лишних цветов).
2. **Палитра в OKLab** — k-means++ и агломеративное слияние; два «чистых» цвета не сливаются, даже если близки; итоговый цвет — точный самый частый цвет кластера (брендовые цвета сохраняются байт-в-байт). Цвета-смеси других цветов отбрасываются.
3. **Разметка с моделью смешивания** — каждый пиксель описывается как `t·A + (1−t)·B`; `t` — доля покрытия.
4. **Удаление спеклов** — мелкие области вливаются в соседа с самой длинной общей границей.
5. **Слои stacked** — слой заходит под верхние слои на 2 px (через max-фильтр по субпиксельному полю) и закрывает дыры, занятые верхними слоями → нет щелей при любом зуме.
6. **Субпиксельные контуры** — marching squares по полю покрытия: граница проходит там, где была реальная граница до растеризации.
7. **Тонкие линии** — гребни тоньше пикселя поднимаются, чтобы не рассыпаться на штрихи.
8. **Готовые фигуры** (идея Vectorizer.AI) — круги, эллипсы, прямоугольники и скруглённые прямоугольники распознаются по моментам площади и SDF и выводятся точными `<circle>/<ellipse>/<rect>` → в Figma это родные Ellipse/Rectangle.
9. **Подгонка кривых** — углы на двух масштабах, регуляризация многоугольников (угол — пересечение прямых сторон), снаппинг почти горизонтальных/вертикальных линий, кривые Безье по Шнайдеру.
10. **Палитра-шаблон** — цвета, близкие к заданным (`--palette`, в плагине — стили и переменные документа), подменяются точными.
11. **SVG для Figma** — фигуры сгруппированы по цвету (`<g id="color-…">`), `id` = имя слоя, без transform/use/style, относительные команды без накопления ошибки округления.

## Качество

```sh
cargo run --release -p png2svg-metrics --bin gen_corpus      # пересобрать corpus/png
cargo run --release -p png2svg-metrics --bin bench           # таблица + report/index.html
cargo run --release -p png2svg-metrics --bin bench -- --check   # как в CI
cargo run --release -p png2svg-metrics --bin bench -- --update  # обновить baseline
```
