# png2svg

Конвертер PNG → SVG высокого качества, заточенный под Figma: без «лесенок», цветной каймы на краях, щелей между фигурами и мусорных точек.

Архитектура и план разработки: [docs/PLAN.md](docs/PLAN.md)

## Структура

| Путь | Что это |
|---|---|
| `crates/core` | Ядро на Rust: весь пайплайн конвертации (без зависимостей) |
| `crates/cli` | CLI `png2svg` |
| `crates/wasm` | WebAssembly-обёртка для Figma-плагина |
| `crates/metrics` | Рендер SVG обратно (resvg) и метрики качества: SSIM, ΔE OKLab; бенчмарк по корпусу |
| `corpus/src` | Эталонные векторные исходники; `corpus/png` — растры, полученные из них |
| `corpus/baseline.json` | Базовые метрики; CI падает при регрессии качества |

## Быстрый старт

```sh
cargo build --release
./target/release/png2svg logo.png -o logo.svg --metrics
./target/release/png2svg icon.png -p icon -s 0.7      # пресет и гладкость
./target/release/png2svg --help
```

## Как работает пайплайн

1. **Детекция антиалиасинга** — пиксели, являющиеся смесью двух соседних цветов, помечаются и не участвуют в построении палитры (нет «бахромы» лишних цветов).
2. **Палитра в OKLab** — k-means++ и агломеративное слияние; два «чистых» цвета не сливаются, даже если близки; итоговый цвет — точный самый частый цвет кластера (брендовые цвета сохраняются байт-в-байт). Цвета-смеси других цветов отбрасываются.
3. **Разметка с моделью смешивания** — каждый пиксель описывается как `t·A + (1−t)·B`; `t` — доля покрытия.
4. **Удаление спеклов** — мелкие области вливаются в соседа с самой длинной общей границей.
5. **Слои stacked** — слой заходит под верхние слои на 2 px (через max-фильтр по субпиксельному полю) и закрывает дыры, занятые верхними слоями → нет щелей при любом зуме.
6. **Субпиксельные контуры** — marching squares по полю покрытия: граница проходит там, где была реальная граница до растеризации.
7. **Тонкие линии** — гребни тоньше пикселя поднимаются, чтобы не рассыпаться на штрихи.
8. **Подгонка кривых** — поиск углов, «заострение» углов (пересечение прямых сторон), снаппинг почти горизонтальных/вертикальных линий, кривые Безье по Шнайдеру.
9. **SVG для Figma** — плоский список `<path>` с `id` = имя слоя, без transform/use/style, относительные команды без накопления ошибки округления.

## Качество

```sh
cargo run --release -p png2svg-metrics --bin gen_corpus      # пересобрать corpus/png
cargo run --release -p png2svg-metrics --bin bench           # таблица + report/index.html
cargo run --release -p png2svg-metrics --bin bench -- --check   # как в CI
cargo run --release -p png2svg-metrics --bin bench -- --update  # обновить baseline
```
